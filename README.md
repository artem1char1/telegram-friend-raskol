# Раскол

Telegram-бот для групповых разговоров на Python и aiogram. По умолчанию использует `openai/gpt-oss-20b` через Groq. Для локального запуска можно выбрать Ollama.

- Упоминание, ответ на сообщение бота или обращение по имени запускают диалог. Имя «Раскол» или «Раскольников» можно поставить в любой части фразы, даже без запятых. Например, «эй раскол бля» или «Чё думы, раскол?». Если фраза двусмысленная, модель проверяет, обращаются ли к боту. Бот выжидает около 3 секунд, чтобы собеседник успел дописать.
- Пока тема открыта, бот может отвечать тому же собеседнику без повторных упоминаний. Модель определяет адресата по смыслу, в том числе в репликах вроде «мне похуй на твои треки». Раскол обычно добавляет встречный вопрос по теме или короткий бытовой вопрос. Если тема закрылась, бот заканчивает диалог. После ответа бот ещё 3 минуты подхватывает продолжение темы. До 10 минут он может снова ответить тому же человеку, если тот обращается на «ты» или по смыслу зовёт бота.
- В чужую беседу бот пробует вступить с вероятностью 8% после серии из трёх сообщений и паузы от 8 секунд. Модель может пропустить ход. После своей реплики бот ждёт 20 минут до следующего случайного включения. Вероятность задаёт `RASKOL_AMBIENT_CHANCE` от 0 до 1.
- После 12 часов без сообщений от участников Раскол окликает группу, например «Чё, блять, молчим? Кто там ещё живой?». Он выбирает реплику случайно без вызова модели. Утреннее приветствие и другие сообщения бота не сбрасывают отсчёт. До следующего сообщения от участника повторного окрика не будет.
- Бот хранит до 20 текстовых реплик на чат или тему в памяти. После перезапуска контекст и таймеры беседы сбрасываются. С Groq часть переписки передаётся в API при запросе к модели. С локальной Ollama контекст обрабатывается на твоём компьютере.

Если после первого запуска новых сообщений ещё не было, отсчёт тишины идёт с момента запуска. Для каждой группы последний момент активности и факт окрика сохраняются в `.raskol/state.sqlite3` при перезапуске. Порог задаётся в `RASKOL_IDLE_MINUTES`. Используй `720` для 12 часов, `1440` для суток и `0` для отключения. Если в твоём `.env` уже стоит старое значение `180`, поменяй его на `720`.

### Утреннее сообщение

В 09:00 по Москве бот пишет в каждую настроенную группу «Доброе утро, …» со случайным обращением, например «Доброе утро, чайники». Для этого сообщения модель не вызывается. Время можно изменить в `RASKOL_MORNING_TIME` (например, `08:30`), часовой пояс в `RASKOL_TIMEZONE` (по умолчанию `Europe/Moscow`). Значение `RASKOL_MORNING_TIME=off` отключает приветствие.

Если процесс запустился с опозданием в пределах двух часов, бот ещё может отправить приветствие. Дата попытки хранится в `.raskol/state.sqlite3`, чтобы после перезапуска сообщение не продублировалось.

Для теста используй отдельную группу. У Telegram есть ограничения на обработку переписки моделями ИИ, а согласие участников привязано к конкретному чату и содержимому. Перед включением бота ознакомься с [условиями Telegram](https://telegram.org/tos/content-licensing#large-language-models-and-ai).

## Запуск в Windows

Нужен Python 3.11 или новее. Команды выполняются в PowerShell из папки репозитория.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

1. Создай бота через [@BotFather](https://t.me/BotFather) и запиши токен в `TELEGRAM_BOT_TOKEN` в файле `.env`.
2. В `@BotFather` выполни `/setprivacy` и выбери **Disable**. Добавь бота в тестовую группу. Если бот уже в группе, удали его и добавь заново. [Privacy Mode](https://core.telegram.org/bots/features#privacy-mode)
3. Запусти бота командой ниже. Отправь в группе `/chatid@имя_бота` и скопируй отрицательный ID из ответа. Останови процесс через Ctrl+C и впиши ID в `TELEGRAM_CHAT_IDS`. Несколько ID можно указать через запятую.
4. Создай [ключ Groq](https://console.groq.com/keys), укажи его в `GROQ_API_KEY` и запусти бота снова. Файл `.env` исключён из Git.

```powershell
.\.venv\Scripts\python.exe -m raskol
```

Для быстрой проверки упомяни бота в обычном сообщении, например «@имя_бота, что думаешь?». Вне групп из списка работает только команда `/chatid` в групповых чатах. Чтобы бот отвечал и писал первым, процесс должен оставаться запущенным.

## Манера речи

Раскол — чат-бот в образе рэпера Раскольникова из «Трагедии Всей Жизни». В неформальном разговоре бот матерится без цензуры, отвечает на детали реплик и подкалывает по ситуации. На прямой вопрос о личности представляется чат-ботом в образе Раскольникова. В [системном промпте](raskol/llm.py) используются вымышленные примеры реплик.

В текстовом интервью заметны самоирония, резкие оценки и переход от общих слов к бытовым деталям. Во фрагменте «Вписки» с 16:54 слышно, как короткие реакции перемежаются с более длинными фразами в живой беседе. ## Локальная модель через Ollama

В запущенной [Ollama](https://ollama.com/) скачай модель.

```powershell
ollama pull gpt-oss:20b
```

В `.env` установи `LLM_PROVIDER=ollama`. По умолчанию бот обращается к `http://127.0.0.1:11434` и использует `gpt-oss:20b`. После изменения настроек перезапусти бота.
